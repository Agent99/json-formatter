# JSON / XML 格式化工具

一款零依赖、单页面的 JSON & XML 在线格式化工具，支持智能修复、交互式树形视图、字段搜索、主题切换等功能。

> **在线使用**：直接双击 `index.html` 在浏览器中打开，开箱即用。

## ✨ 功能特性

| 功能                      | 说明                                                                |
| ------------------------- | ------------------------------------------------------------------- |
| **自动检测**        | 粘贴内容后自动识别 JSON / XML / Java toString 格式                  |
| **Java 对象转换**   | 支持解析 Java `toString()` 格式（如 `{a=1, b=2}`）并转换为 JSON |
| **格式化 / 压缩**   | 一键美化或压缩为单行                                                |
| **交互式树形视图**  | JSON / XML 解析后自动展示，支持节点折叠/展开                              |
| **字段/值搜索跳转** | 搜索字段名或值，高亮匹配并支持 ▲▼ 跳转，显示完整层级路径         |
| **悬停路径提示**    | 鼠标悬停字段名时显示完整 JSON 路径（如 `$.data.list.name`）       |
| **任意层级复制**    | 每个节点（对象/数组/叶子）均可独立复制                              |
| **Key 排序**        | 递归按 A-Z 排序所有 JSON Key                                        |
| **智能错误修复**    | 精确定位错误行号，6 种自动修复策略，差异对比可视化                  |
| **字符串化 JSON**   | 自动识别并反转义 `"{\"a\":1}"` 这类双重编码内容                   |
| **可拖拽分栏**      | 左右面板支持拖拽调整宽度，双击分隔线可恢复默认比例                  |
| **增强 XML 支持**   | 支持 XML 树形搜索、节点路径与复制；保留声明、DTD、实体、混合文本与 CDATA                |
| **白天 / 黑夜主题** | 右上角一键切换，偏好自动记忆                                        |

## XML 使用说明

- 选择「XML 示例」后加载，即可体验标签、属性、重复节点、命名空间和 CDATA 的树形展示。
- 树形搜索可匹配标签、属性名及值，路径如 `/orders[1]/order[2]/@id`；复制元素会补齐继承的命名空间。
- 格式化与压缩直接处理原始 XML 标记，保留声明、DOCTYPE（含内部子集）、实体引用、引号和文本内容。
- 含文本或 CDATA 的混合内容子树，以及 `xml:space="preserve"` 子树保持原样；其他元素间的纯空白视为排版缩进，可重排或移除。对空白有业务含义的报文请使用 `xml:space="preserve"`。
- 压缩不强制删除有意义的换行，因此 CDATA 或保留空白的内容仍可能包含多行。
- 元素复制使用浏览器 XMLSerializer，生成语义有效的 XML，不保证实体引用、引号等原始写法完全一致。
- XML 语法由浏览器 DOMParser 校验，不提供 DTD / XSD schema 校验。

## 回归验证

通过本地 HTTP 服务打开 `tests/xml-regression.html`，页面会自动验证 XML 格式化幂等性、文本保留、DTD、命名空间、搜索路径及 JSON 回归行为。

```bash
python -m http.server 8000
# 浏览器打开 http://localhost:8000/tests/xml-regression.html
```
